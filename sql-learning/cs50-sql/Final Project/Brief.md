# Final Project: Verified Financial Assistance Platform (VFAP)

## Overview

The **Verified Financial Assistance Platform (VFAP)** is a conceptual database system designed to improve the transparency and efficiency of financial aid distribution by connecting verified beneficiaries with donors and organizations.

The project addresses a common challenge faced by charitable initiatives and humanitarian organizations: ensuring that financial assistance reaches individuals with verified needs while maintaining accurate records, accountability, and trust.

VFAP was developed as the final project for **CS50's Introduction to Databases with SQL**, bringing together the database design principles and SQL concepts learned throughout the course.

---

## Project Objectives

The platform aims to:

- Store information about individuals requesting financial assistance.
- Record verification details to ensure applicants meet eligibility requirements.
- Track financial assistance requests and their status.
- Manage donations and funding sources.
- Improve transparency and accountability throughout the assistance process.
- Maintain relationships between applicants, verifications, donations, and assistance records.

---

## Database Design

The database was designed using relational database principles with a focus on:

- Normalized database design
- Primary and foreign key relationships
- Data integrity through constraints
- Efficient querying of related information
- Clear separation of entities and responsibilities

---

## Concepts Applied

This project incorporates many of the concepts covered throughout the CS50 SQL course, including:

- Relational database design
- Entity relationships
- Primary and foreign keys
- Database normalization
- SQL queries
- Database views
- Data integrity constraints

---

## Motivation

The idea for VFAP originated from the observation that many individuals and families in need struggle to connect with organizations capable of providing financial assistance, while donors and charitable organizations often require reliable methods to verify needs and manage aid effectively.

Although this project is presented as a database design exercise, it demonstrates how relational databases can be used to model real-world social challenges in a structured and scalable manner.
